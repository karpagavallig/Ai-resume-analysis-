Ai-resume-analysis-
  AI Resume Analyzer is a Flask-based web application that analyzes PDF/DOCX resumes and generates ATS scores, skills, strengths, missing skills, and improvement suggestions. It also improves resume bullet points and generates downloadable PDF reports using Python, Flask, SQLite, HTML, CSS, and JavaScript
